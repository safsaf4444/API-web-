AI Engine
Free AI — no key needed
Gemini 1.5 Flash is included by default with no API key required. Groq (Llama 3.3 70B) serves as an automatic fallback when Gemini quota is reached.
BYOK — Bring Your Own Key
Set your own API key on the AI page to unlock premium models. Keys are auto-detected by prefix:
sk-ant- → Anthropic Claude  ·  AIza → Gemini Pro  ·  gsk_ → Groq  ·  anything else → OpenAI

Keys are encrypted with Fernet before being stored. The frontend never stores your key in localStorage.
AI Endpoints
POST /ai/summarize — structured summary of a paper's abstract
POST /ai/ask — answer a specific question about a paper
POST /ai/set_key · GET /ai/key_status · DELETE /ai/clear_key
Semantic Scholar
API Key (Optional)
Semantic Scholar rate-limits unauthenticated requests aggressively. To reduce 429 errors, add your key to the backend environment:

SEMANTIC_SCHOLAR_API_KEY=your_key_here

Then restart the backend. The key is backend-only and never stored in the frontend.
