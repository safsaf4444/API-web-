About Seren
A unified medical evidence platform designed to search, synthesize, and organize research efficiently. Built for speed, transparency, and evidence-based medicine.
Platform Access
Guest Mode
Search and open papers from Europe PMC, Semantic Scholar, OpenAlex, and Crossref instantly. Full-text Open Access loading and DOI resolution are fully available without an account.
Registered Users
Creating a free account unlocks the core research workflow:
• Save papers to a personal library & organize with folders
• Annotate papers and participate in comment threads
• Use AI summarization and PICO extraction
• Manage BYOK (Bring Your Own Key) for premium AI models
AI Infrastructure
Included Free Tier
Gemini 1.5 Flash is integrated by default—no API key required. If the global quota is reached, the system automatically falls back to Groq (Llama 3.3 70B) to ensure uninterrupted access.
BYOK (Bring Your Own Key)
Power users can set their own API keys on the AI settings page to unlock premium models. Keys are auto-routed based on their prefix:

sk-ant- → Anthropic Claude  ·  AIza → Gemini Pro  ·  gsk_ → Groq  ·  anything else → OpenAI

Security note: Keys are encrypted at rest using Fernet symmetric encryption. The frontend never stores your key in localStorage.
API Endpoints
POST /ai/summarize — Generates a structured summary of a paper's abstract.
POST /ai/ask — Runs a custom Q&A against the paper's metadata.
POST /ai/set_key · GET /ai/key_status · DELETE /ai/clear_key
External Providers
Semantic Scholar API Limits
Semantic Scholar aggressively rate-limits unauthenticated requests. To reduce 429 errors in your own deployment, add an API key to the backend environment variables:

SEMANTIC_SCHOLAR_API_KEY=your_key_here

This key remains strictly on the backend and is never exposed to the client.
