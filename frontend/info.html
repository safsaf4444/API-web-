About Seren
A unified medical evidence platform designed to search, synthesize, and organize research efficiently. Built for speed, transparency, and evidence-based medicine.
Platform Access
Guest Mode
Search and open papers from Europe PMC, Semantic Scholar, OpenAlex, and Crossref instantly. Full-text Open Access loading and DOI resolution are fully available without an account.
Registered Users
Creating a free account unlocks the core research workflow:
• Save papers to your personal library & organize with folders
• Annotate papers and participate in comment threads
• Use AI summarization and Q&A
• Manage BYOK (Bring Your Own Key) for premium AI models
AI Infrastructure
Included Free Tier
Gemini 1.5 Flash is integrated by default—no API key required. If the global quota is reached, the system automatically falls back to Groq (Llama 3.3 70B) to ensure uninterrupted access.
BYOK (Bring Your Own Key)
Power users can set their own API keys on the AI settings page to unlock premium models. We currently support automatic routing for:

• OpenAI (GPT-4o, GPT-4o-mini)
• Anthropic (Claude 3.5 Sonnet)
• Google (Gemini Pro)
• Groq (Llama 3.3)

Security note: Keys are encrypted at rest using secure symmetric encryption. The frontend never stores your key in your browser's local storage.
